# COD 战役研究：先弄清楚一次遭遇战在要求玩家判断什么

日期：2026-11-11。对象为《使命召唤》本体，选取 MW2019《清理门户》和 MWII（2022）《黑暗水域》，不将此前的 Saltline 网页演示当作 COD。

## 实际做了什么

本机安装目录及 G 盘按游戏名、常见启动文件检索后，未找到可运行的 COD 或安装包。本轮采用玩家自行录制的游戏画面与开发者一手访谈：对第一份录像在 00:30—06:20 之间定位32个画面，对第二份在 02:00—14:00 定位9个画面，并在约09:58—10:04正常播放、连续采样回看箱体交火。时间码仅对应下面两份录像，不代表关卡固定触发时间。

- [FractureGrid：《清理门户》，06:36](https://www.bilibili.com/video/BV1Bs4y1p7nG/)
- [小香草行不行：《黑暗水域》，第9集，16:14](https://www.bilibili.com/video/BV1D14y1j7sT/?p=9)

这是视觉观察和文献研究，未亲自操作 COD，也未获得可用于主观评价的可靠听觉或生理感受。录像中的弹幕不作为设计证据；观察无法代替玩家对紧张感、晕动和乐趣的判断。

## 画面里具体发生了什么

| 录像位置 | 可复查的观察 | 对设计作用的推断 |
| --- | --- | --- |
| 清理门户 00:30—00:55 | 队友在入口集结、占位，随后进入；场景从室外切换到狭窄室内。 | 玩家能先看见即将进入的空间和同伴的位置，进入前已有准备阶段。 |
| 清理门户 01:24—01:40 | 队友停在门边，玩家视线沿门框探入；短暂交火后出现安全确认，视线再转向下一处开口。 | 门框限制一次能看见多少区域，推进、观察与交火交替出现。 |
| 清理门户 02:24—03:00 | 门后警告、靠门侧观察、室内交火、确认后继续；家具和开口决定看得见的范围。 | 危险有具体的位置，角色指令能对应到空间中的行动。 |
| 清理门户 05:14—05:38 | 抱婴儿的女性、下一扇门、床底的人、清场确认与换弹出现在相邻段落。 | 画面要求辨认人物及其行为；把遇见的人都当成相同靶子会损失这一层判断。 |
| 黑暗水域 07:00、08:00、09:00 | 瞄具指向平台建筑开口，接着登梯推进，再转入快艇追赶与撞入船体。 | 目标、观看距离和移动方式变化，改变的是正在解决的问题。 |
| 黑暗水域约09:58—10:04 | 玩家在甲板箱体之间观察、瞄准和前进；船体倾斜、箱体位移让遮挡与通路改变。 | 同一个位置能否继续提供掩护会变化，移动有了场景内的理由。 |

本段归纳：一次遭遇战需要让玩家知道哪里值得观察、什么正在构成威胁、自己的动作产生了什么后果。关于它是否让人感到有趣，目前只是需要试玩验证的假设。

## 开发者明确解释了哪些关系

MW2019 单人设计负责人 Jacob Minkoff 解释，Townhouse 使用住宅实际尺度，盲角和狭窄空间影响进入方式；他们把场地放到动捕空间，观察顾问小队怎样通过。队友提醒检查拐角，需要由实际危险兑现。这个解释支持审查“空间、指令与后果是否一致”，不支持“把地图缩小就会好玩”。[Activision 开发者访谈，2019-09-25](https://blog.activision.com/call-of-duty/2019-09/The-Narrative-of-Modern-Warfare-Part-1)

《黑暗水域》的开发者说明，为了让移动箱体与交火成立，他们扩大船体、重做战斗布局，并让 AI 应对箱体的位置变化。由此值得检查的是环境变化怎样影响掩护和路线，不能只复制一个移动箱子模型。[Infinity Ward / Activision Shanghai 制作访谈，2022-08-16](https://www.callofduty.com/ca/en/blog/2022/08/call-of-duty-modern-warfare-II-dark-water-deep-dive)

## 对我们这版的检查结果与本轮改动

我们的目标点很多，但阶段文字变化并不总能对应到玩家正在观察、处理的危险。这需要按遭遇战继续检查，暂不把上面两关归纳成整个 COD 系列的公式，也不直接改造全部地图。

另一个能立即复现的问题是：游戏实际扣弹和扣血，却没有发出前端已经订阅的 `shot`、`hit`、`hurt` 事件。因此枪声、命中音、受伤音与准星命中确认没有被战斗触发；枪口特效和枪械动作仍然存在。普通难度全战役打出96发、96次命中时，这三类反馈事件原来均为0。

v1.0.1只修复这一条已有链路：实际开枪通知枪声、实际造成伤害通知命中确认、实际减少生命通知受伤反馈。未击中、墙体遮挡、护甲未解除、空弹匣不能得到虚假的命中确认。镜头仍保持既有的晕动控制。

三个反馈专项先在旧版本全部失败，修复后全部通过；总检查为12项通过。八关输入代理结果仍为5782步、96发、96次命中、40次击杀、零死亡。浏览器受控靶标测试实际单击后弹药24→23、目标生命52→13，收到一次开火和一次命中，准星确认出现，WebAudio输出非零。

这项修复恢复了辨认结果所需的信息，并未证明玩法已经有趣。后续应拿一段既有遭遇战验证：玩家能否在受伤前辨认危险、改变位置是否有用、完成动作后是否知道接下来发生了什么。不能用增加章节或通过通关测试来代替这些判断。
